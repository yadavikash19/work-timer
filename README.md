# Work Timer

Counts only the time you actually work on your laptop: any key press or mouse move is work, no input for a couple of minutes is a pause (and those minutes are taken back). It knows which app or site is in front, keeps YouTube junk and social media out, and races you against friends on a private leaderboard that only sees totals.

Website and downloads: https://worktimer.worktimer-site.workers.dev

Version 2 is one app for Windows and Mac with built-in updates (Tauri: Rust core, web dashboard).
